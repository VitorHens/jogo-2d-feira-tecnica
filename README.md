# feira_t-cnica_1ano
Este projeto é um jogo 2D desenvolvido na Unity para a Feira Técnica da escola. O jogo conta com diferentes fases, inimigos, sistema de experiência, habilidades e desafios que aumentam conforme o jogador avança.

Durante o desenvolvimento, foram utilizados scripts em C# para controlar a movimentação, o surgimento dos inimigos, ataques, menus, animações e outras mecânicas. O projeto também inclui sprites, cenários, prefabs e telas de vitória e derrota.

Esse trabalho foi uma oportunidade de colocar em prática conhecimentos de programação, criação de jogos e trabalho em equipe, passando por todas as etapas — desde a ideia inicial até a construção das fases e da jogabilidade.
